# AI Reception Voice Agent 🎙️

An AI-powered receptionist that converts caller voice into text, understands queries, extracts caller details, and stores call records.

## Features

- Voice input processing
- Speech-to-text conversion
- AI conversation analysis
- Caller information extraction
- MongoDB call storage
- Call history tracking

## Technologies

- Python
- Streamlit
- Groq AI
- Whisper Speech Recognition
- MongoDB

## Run Project

Install dependencies:

pip install -r requirements.txt

Run:

streamlit run app.py
